# Furia de Dragones - Gestor de Builds de Albion Online

Mini web para el gremio **Furia de Dragones** de Albion Online. Incluye un gestor de equipamiento (builds) integrado con los iconos de la API oficial de Albion y selector de habilidades.

## 🚀 Cómo publicar en GitHub Pages

1. **Sube estos archivos a tu repositorio de GitHub**:
   - Crea un repositorio nuevo en GitHub (por ejemplo, `FuriaDragonesWeb` o `furia-de-dragones`).
   - Sube todos los archivos de esta carpeta a la rama `main` o `master`.

2. **Activar GitHub Pages**:
   - En tu repositorio de GitHub, entra a **Settings** (Configuración) > **Pages**.
   - En **Build and deployment** > **Source**, selecciona **GitHub Actions** (o bien **Deploy from a branch** seleccionando la rama `main` y la carpeta `/ (root)`).
   - ¡Listo! En 1-2 minutos tu web estará disponible en `https://TU_USUARIO.github.io/NOMBRE_DEL_REPO/`.

## 🛡️ Funcionalidades

- **Equipamiento completo**: Casco, Pecho, Botas, Arma Principal, Mano Secundaria, Capa, Comida, Poción y Montura.
- **Selector de Habilidades**: Configuración de habilidades Q, W, E, D, R, F y Pasivas según el arma y armadura equipada.
- **Tiers y Encantamientos**: Selección de Tier (T4 - T8), Encantamiento (.0 - .4) y Calidad con iconos oficiales de Albion.
- **Guardado y Gestión**: Guarda builds en el navegador para tenerlas siempre a mano.
- **Compartir y Exportar**:
  - Enlace directo compartible (guarda la build en la URL).
  - Copiar formato texto para pegar en Discord.
